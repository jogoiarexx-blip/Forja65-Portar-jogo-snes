# Identificação das versões

| Item | Identificador | Observação |
|---|---|---|
| Pacote de fonte | REV216 | Entrega organizada em ZIP completo |
| Base do runtime | REV215 | Não atualizada durante a organização |
| Identidade interna do motor | `0.4.36.121-rev210-rev208-hw-timing` | Valor já presente em `forja65-core.js` |
| Aplicação Web | Interface portátil do ZIP REV216 | Mesmos bytes do arquivo fornecido |

A numeração da entrega e o valor interno do motor/cache são conceitos diferentes. Renomear arbitrariamente a identidade interna pode invalidar artefatos em cache. O valor de versão antigo foi preservado no histórico do pacote completo.
